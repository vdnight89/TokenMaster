# TokenMaster 设计说明 · Round 02

任务目录：`design/round-02/`。本轮目标：**放弃 Round 01 三个方向**（配电房/总机台账/筹码室均被否），按用户指定参考重新设计——**充分借鉴 Antigravity Manager（主）与 zcode-pool（辅）的 UI**，覆盖 v1 全部功能，配充足的图表/图示（用量、余量、速度等）。

## 品类三问

- **品类**：开发者桌面控制台 / 账号池管理工具（暗色、高频、专业）。
- **首屏看什么做什么**：网关是否在跑、今日用量与吞吐、池子健康、今天该处理什么（签到/领取/临期/过期）。
- **同类最好怎么做**：AM（药丸导航+统计卡+QuotaItem 配额行+监控表）、zcode-pool（状态栏 KPI 条+SVG 仪表盘+吞吐曲线+延迟直方图）。直接沿用这套已被用户认可的地板。

## 页面与功能覆盖（对照 spec v1 用户故事 1–35）

1. **仪表盘**：KPI 状态栏（网关/今日请求/tokens/吞吐/平均 TTFB/池健康）；今日待办 5 条（可领套餐→领取、待签到→一键签到、临期积分、token 过期）；吞吐曲线；Provider 池额度仪表盘（带刻度 SVG 量表）；错误分布；最近请求表。（故事 1/23/25/26/27/34）
2. **账号**：搜索+过滤分段（全部/可用/限流/临期/异常/停用）+视图切换；账号卡网格（Provider 彩色芯片、状态徽标、tier 渐变徽标、QuotaItem 配额行含重置/过期时间、行内操作）；特殊状态卡（429 冷却倒计时、失效横幅、临期徽标）；添加账号模态（OAuth/设备码/扫码短信/手动粘贴四类引导 + zcode-pool 导入）。（故事 4–10/28）
3. **网关**：运行卡（启停、端口、base_url、双协议面）；网关密钥卡（sk-tm-… 掩码/复制/重置/禁用）；模型映射表（裸名→provider 模型，优先级排序）；选号策略卡（先到期/剩余最多+临期分档+重试/冷却参数）；路由拓扑图示。（故事 2/3/11–15/19/20）
4. **用量**：时间分段；6 张渐变汇总卡；堆叠面积图（按模型趋势）；堆叠柱状图（in/cache/out）；Provider 占比环图；账号消耗 Top 横条；7×24 请求热力图；延迟直方图（P50/P95）；聚合明细表。（故事 23/24）
5. **日志**：搜索+快捷过滤 pill；监控表（状态 pill/方法/模型/账号/路径/tokens/TTFB/耗时/时间）；行展开=换号轨迹时间线+原始错误。（故事 34）
6. **接入**：base_url+网关密钥复制卡；客户端配置示例 tabs（Claude Code/Cline/Continue/Codex/任意 SDK）；可用模型列表；不代写客户端配置的边界说明。（故事 35/18）
7. **设置**：语言/自启/托盘/关窗行为；出站代理三级覆盖（全局→按 Provider 表→按账号）；数据目录。（故事 29–33）

## 图表清单（11 类，全部手绘 SVG/JS，无外部依赖）

吞吐面积曲线、堆叠面积趋势、堆叠柱状、占比环图、横向条形排行、7×24 热力图、延迟直方图、带刻度 SVG 仪表盘、QuotaItem 内嵌配额条、表格迷你近况柱、路由拓扑图示。

## 动效（三处基本动效）

1. 页面切换 160ms 淡入上移；
2. 网关启停拨杆 + KPI 状态联动变色；
3. 一键签到：loading→成功落章 toast + 待办行划除。辅：复制按钮对勾交换、日志行展开、吞吐曲线每 2s 推进。

## 模拟数据与边界

单一 `DATA` 对象贯穿七页（42 账号/15 Provider/今日 1,247 请求/2.31M tokens），数字跨页一致；全部为原型模拟数据，不写进界面文案。暗色单主题（桌面常驻工具）；1280×900 目标视口。

## 评审与验证记录（2026-10-06）

- **独立视觉评审**：documents:visual-judge 子代理，共 5 轮（2 组并行初审 → 修复 → 复审 ×3 轮收敛）。最终结论：7 页 + 3 模态 + 200% 局部全部 pass。轮次要点：
  - R1：添加账号模态布局塌破（chevron 图标无尺寸约束）、`--full` 因内部滚动容器失效 → 修复 `.opt svg` 尺寸、增加 `?scroll=full` 长图模式
  - R2：数据口径矛盾（成功率/Trae 仪表/TOKENS 分量/环图 vs 汇总卡）、路由拓扑未渲染、单选行文字粘连 → 统一为 `RANGE_META` 单一口径源、补 `renderTopo` 调用、rlabel 块级化
  - R3/R4/R5：KPI 副行截断、Gemini 仪表副标格式、拓扑连线压字 ×2、Top6 账号名裁切与单位 → 全部修复并逐项复核通过
- **动效探测（shoot --motion）**：网关页入场动画（6px 位移 + 0.96 透明度变化）与启停操作反馈（8px + 0.84）检测通过；仪表盘签到操作反馈（2 元素、10px、0.96）检测通过。仪表盘"首次进入"采样窗口未捕获 160ms 页面切换动画（网关页已证实该动画存在）。滚动叙事不适用（工作区控制台，非落地页）。
- **证据**：`shots/` 下 7 页整页长图、3 个模态、200% 局部、2 份动效报告（motion-dash / motion-gw 的 report.json）。
- **边界**：出站代理"测试连接"、签到/领取、密钥重置等为原型模拟反馈（toast），未接真实业务；未做亮色主题（暗色单主题）；未做账号表格视图（仅卡片网格）；语言切换为视觉占位。
