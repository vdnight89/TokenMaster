# TokenMaster 设计说明 · Round 01 方向探索

任务目录：`design/round-01/`。本轮目标：为桌面客户端 GUI 探索 3 个设计方向，做成对比页供用户选定。对比页：`style-explorer.html`。

## 用户与任务（三行）

- **核心对象**：账号（一条 Provider 凭据）。一眼认出它靠：Provider 归属、身份名、状态（正常/限流冷却/失效/停用）、额度余量。用户最怕错过的随时间变化的量：**临期额度作废**、**token 过期掉线**、**限流冷却剩余时间**——必须做成对象上最显眼的属性。
- **主动词**：监控池况 + 逐条处理异常（过期/限流/待签到/待领取），辅以比较（用量账本）。
- **频率**：开发者自用，网关常驻后台，GUI 每天看几次、每次几分钟——高频专业工具，密度偏高、键盘友好。

首屏要回答"我现在该处理什么"（今日待办 + 池子健康），不是"总共有多少"（指标卡仪表盘）。三个方向都遵守：导航+标题不超两行，首屏直接是对象本身。

## 调性（五刻度，含依据）

| 刻度 | 取值 | 依据 |
| --- | --- | --- |
| 能量 | 安静为主，异常局部高能 | 托盘常驻工具平时不打扰，出事要一眼跳出来 |
| 完成度 | 精密 | 开发者受众：等宽数字、严格对齐 |
| 密度 | 偏密 | 每天多次使用的自用专业工具，一屏 15+ 账号 |
| 分量 | 中 | 数据是主角，避免消费级的轻飘 |
| 严肃度 | 偏庄重，允许一个方向取活泼端 | 生产力工具；筹码室方向故意走到活泼重的一端做对比 |

## 品类与标杆拆解

品类：**开发者桌面控制台 / 账号池管理工具**。风格最鲜明的标杆选 Linear（暗色高频工具）与 1Password 桌面版（亮色对象浏览工具）各拆一家。

**Linear 拆解（8 条）**
1. 控件：4px 小圆角、1px 细边框、hover 提亮 2%，无重阴影——密集内容不被控件打断。
2. 字体：13px/1.45 正文，标题 15px/600——信息密度优先。
3. 颜色：近黑底、文本三阶灰、品牌紫低频出现——把颜色让给用户内容的状态与标签。
4. 图标：14px 线性、粗细统一、弱化存在。
5. 状态反馈：乐观更新 + 150ms 过渡，失败回滚 toast——高频操作的连续感。
6. 动效：120–180ms，只做位置/透明度，无弹跳——专业工具不表演。
7. 文案：短、动词开头、无感叹号。
8. 首屏：视图即内容（收件箱/我的议题），导航一行——"该处理什么"优先。

**1Password 桌面版拆解（6 条）**
1. 左侧对象列表 + 右侧详情的主从结构——对象浏览型工具的地板。
2. 亮色 + 单一安全蓝强调 + 大量留白——信任感。
3. 列表行：图标 + 名称 + 次级元数据单行紧凑。
4. 状态用色点/标签，不整行变色。
5. 危险红只出现在动作上。
6. 顶部常驻快速搜索，键盘优先。

**取舍**：留下——密度适配高频、状态色点语义、乐观更新短动效、首屏=待处理内容、键盘优先。换掉——Linear 紫、1Password 蓝这类"行业默认色身份"，改由 TokenMaster 自己的领域隐喻（配电/总机/筹码）推出各自的色彩身份；"侧栏+列表"的地板只在台账方向沿用，其余两向换骨架。

## 方向卡

### A · 配电房（breaker）

- **北极星**：像管理一面配电箱：每条回路一眼看清负载，跳闸的回路红灯亮起，推上去就恢复。
- **生成引擎**：其他领域的整套表现形式——电气配电盘。来自产品的证据：网关=配电、限流=过载跳闸、额度=电表读数、Provider=回路、账号启停=断路器通断。
- **首屏骨架**（工作区）：监控/面板骨架。顶部分段导航一行；主区为 Provider"回路模块"纵向堆叠，每模块内是 32px 断路器行（LED + 名称 + tier + 额度条 + 等宽读数 + 到期 + 拨杆）；底部电表读数条（今日 tokens 大号等宽 + mini 负载条）。
- **字体**：Segoe UI/微软雅黑；铭牌标签全大写 + 字距加宽；一切数字 Cascadia Mono 等宽。
- **色彩**：面板炭 `#17191D`/`#1E2126`、槽位 `#22262B`、线 `#2E333A`、文本 `#E8EAED`/`#8B939D`、琥珀 `#FFB020`（强调/警示）、通 `#38C172`、跳闸 `#FF5C5C`。
- **主视觉**：整面配电面板本身就是主视觉；LED 微光（≤4px 光晕）是唯一的"发光"。
- **图标**：不用插画图标；用 LED 圆点、拨杆、铭牌刻字这些面板元素当图标。
- **控件语法**：直角 2px 圆角、1px 硬边框、按下不变形单亮灯；开关是纵向拨杆，到位有 120ms 滑动。
- **动效**：咔嗒——推拨杆；跳闸的断路器行 LED 闪烁 + 展开红色检修面板（`?state=tripped`）；电表数字滚动。三处呼应：LED 常亮→闪烁→熄灭对应正常→异常→停用。
- **结构性突破**：没有指标卡区——"总览"就是一面按 Provider 分组的面板，今日读数压进底部一条电表条。
- **记忆点**：tm-03 跳闸行的检修面板（429 · 冷却 04:32 · 重试/换号）。
- **放弃**：圆角胶囊、渐变、大面积发光弥散、插画。

### B · 总机台账（ledger）

- **北极星**：像一位老式总机接线员：插孔板上的灯在闪，把每一次请求接到正确的线路上，台账上一笔记一笔。
- **生成引擎**：历史媒介与前沿技术的并置——老式电话总机 + 铅印台账。来自产品的证据：gateway 本义是"总机"，请求被路由=接线，用量=通话记录，网关密钥=专线凭证；AI 抽象服务借印刷品的实物分量。
- **首屏骨架**（工作区）：收件箱/队列骨架的三段式——左窄目录（台账簿目录）+ 中待办队列（今日 5 件，编号 No.084x）+ 右登记卡（当前对象全部字段与处理动作）。
- **字体**：标题 SimSun/Georgia 衬线；正文宋体 13px；编号与数字 Courier New/Consolas 打字机体；台账标题用"卷·页"式小注。
- **色彩**：纸 `#F5F1E8`、墨 `#1D1A16`、次级 `#5A5347`、表格线 `#D9D2C2`、邮戳红 `#B23A2E`（唯一强调，只给异常与印章）、登记蓝 `#2C5F8A`（次强调，极少）。
- **主视觉**：铅印排版本身——双细线、点线引导、印章徽章；无图片。
- **图标**：不用图标；用编号、印章、铅字符号（§、No.、※）。
- **控件语法**：直角或 1px 圆角、墨色 1.5px 边框按钮、hover 反白（墨底纸字）；选中=2px 墨框；印章徽章旋转 -3°。
- **动效**：落笔——队列选中时详情切换 150ms 淡入；盖章——签到完成后红章 scale 1.6→1 落下（`?state=stamp`）；台账新行从上滑入。
- **结构性突破**：完全亮色的单色印刷界面，正面打破"AI 工具=黑底紫光"品类套路；首屏没有一张指标卡，是"待办队列+登记卡"。
- **记忆点**：签到盖章的一刻（红章落下 + 编号+1）。
- **放弃**：阴影、渐变、暗色、圆角卡片、LED/霓虹。

### C · 筹码室（cage）

- **北极星**：像坐在筹码室柜台后：每一摞筹码是一家 Provider 的额度，随手可数，兑付窗口灯火通明。
- **生成引擎**：一个具体场景+材质——午夜牌桌筹码室（毛毡、黄铜、筹码）。来自产品的证据：Token 字面即筹码；池=奖池；轮询=发牌轮流；额度余量天然是"可以摞起来的量"。
- **首屏骨架**（工作区）：画廊/货架骨架——桌位筛选行 + 桌位卡片网格铺满首屏；每张桌位=Provider，筹码摞=账号与额度（把数字画成看得见的量）。
- **字体**：Segoe UI 粗体宽字距做标题；数字 Cascadia Mono 粗体大号（筹码刻字感）。
- **色彩**：毛毡绿 `#123527`/`#174634`、围栏 `#0D281D`、象牙 `#F2ECDB`、黄铜 `#C9A227`（线条与次强调）、筹码红 `#C0392B`（Pro/警示）、筹码蓝 `#2E6F8E`（Lite）。
- **主视觉**：筹码摞本身——每枚筹码一个账号，高度即池深，颜色即 tier，临期挂黄铜小牌，冷却变灰斜放。
- **图标**：不用常规图标；筹码、黄铜牌、柜台徽记承担图形角色。
- **控件语法**：12px 圆角、黄铜 1px 描边、hover 筹码抬起 2px + 阴影加深；按钮象牙面黄铜边。
- **动效**：收筹——签到点击后一枚新筹码落入摞顶（translateY+scale，200ms，`?state=checkin`）；桌位 hover 整摞微抬；兑付计数滚动。
- **结构性突破**：额度不是进度条而是物理堆叠的筹码；首页是"货架"不是列表。
- **记忆点**：签到收筹落进摞顶的一刻。
- **放弃**：表格、细线框、白底、小字高密度。

线框三个骨架互不相同 ✓（面板监控 / 三段收件箱 / 货架画廊）。

**通用四项**（首屏骨架、字体、色彩、主视觉）：任意两方向零项相同 ✓（衬线打字机 vs 等宽工业标签 vs 粗体宽距；纸墨红 vs 炭琥珀 vs 绿毡黄铜；台账铅印 vs 配电面板 vs 筹码摞）。

**工作区四项**（骨架、对象样子、导航、密度）：断路器行/台账条目/筹码摞；顶部分段/左竖目录/顶部筛选行；密/中/中低——任意两方向至多一项相同 ✓。

**其他**：不按明暗分方向（各自色相家族不同，明暗是结果）✓；B 走到单色印刷极端且打破"AI 工具黑底紫光"套路 ✓；C 走到活泼重的一端 ✓；无方向与 Linear/1Password 撞脸（沿用"首屏=待处理内容"地板不算撞脸）✓。

## 小样说明

- 三个小样共享同一份示例数据（15 家 Provider、zcode 展开 5 账号、今日 1,247 请求 / 2.31M tokens、5 条待办），实现互不共用。
- 均为桌面 1280×900、系统字体、无网络资源；`interactive: true`（Alpine.js）：A 推拨杆/展开检修面板，B 切换队列/盖章，C 签到收筹。
- 地址参数状态：A `?state=tripped`，B `?state=stamp`，C `?state=checkin`。
