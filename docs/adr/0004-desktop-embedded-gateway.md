# 网关仅桌面内嵌运行，不提供无头模式

网关服务（axum）运行在 Tauri 桌面应用进程内，随 GUI 启停；v1 不提供独立 CLI/服务/ docker 无头部署形态。理由：TokenMaster 定位是个人桌面工具，无头模式（AM 有 docker 变体）带来的配置对等、双入口维护成本在 v1 不划算。

## Consequences

- GUI 退出即网关停止；如需常驻，依赖「最小化到托盘」而非服务化（是否做托盘常驻在实现期按 zcode-pool 的既有设计定）。
- 未来若需要无头模式，网关核心必须保持与 Tauri 运行时解耦（纯 Rust 库 + 薄命令层），这是本决策对代码结构的约束。
